# SSH 隧道

> 有以下开发场景：本地开发环境的电脑ipv4地址为`192.168.31.27`，通过登录公司VPN，连接到了远程桌面地址`192.168.146.42`。远程桌面为物理机，其能够访问实验室环境的前后端项目，项目部署地址为`172.16.67.20:8080`，，某个业务模块的ws接口地址为`172.16.67.20:9540`。

需求：想要在本地开发环境请求远程桌面项目的业务模块接口，以此实现调试。

具体步骤：
1. 连接VPN
2. 以管理员命令打开PowerShell，并输入一下命令
```bash
ssh -L 9540:172.16.67.20:9540 Administrator@192.168.146.42
```
