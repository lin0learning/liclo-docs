# 编程概念

## 有符号与无符号

先说结论：

- `int32_t` 是 有符号 32位整数。
- `uint32_t` 是无符号 32位整数。

核心区别在于“最高位（最左边的那一位）”用法不同。



### 1. 有符号（Signed）是什么意思？

以 `int32_t` 为例，它占 **32个比特位（bit）**。

- **第1位（最高位）** 被当作 **符号位**。
  - `0` 代表正数，`1` 代表负数。
- **剩下的31位** 才用来存储数值。

**取值范围**：
因为有一位被占去当符号了，所以它能表示的数范围是 **-2^31 ~ 2^31 - 1**，也就是 **约 -21亿 到 +21亿**。

**生活中的类比**：
就像温度计上的 **“+/-”号**。`+10` 代表零上10度，`-10` 代表零下10度。虽然都是10，但正负号决定了物理意义完全不同。

### 2. 无符号（Unsigned）是什么意思？

以 `uint32_t` 为例，它也占 **32个比特位**。

- **没有符号位**！所有32位全部用来存储数值本身。
- 因为它不需要记录正负，所以它**只能表示非负数（0和正数）**。

**取值范围**：
所有位都用来存数，它能表示的范围是 **0 ~ 2^32 - 1**，也就是 **0 到 约42亿**。比有符号的正数范围整整大了一倍。

**生活中的类比**：
就像汽车的 **“里程表”**。里程数只会增加，永远不会显示负数（你不可能倒着开让里程变成 -100 公里）。



### 3. 最关键的陷阱（初学者必看）

当你给无符号数赋一个负数时，它**不会报错**，而是会变成一个极大的正数（发生“溢出环绕”）。

举例：

```cpp
#include <iostream>
#include <cstdint>

int main() {
    uint32_t a = 10;   // 正确
    uint32_t b = -1;   // 危险！不会报错！

    std::cout << "a = " << a << std::endl;  // 输出 10
    std::cout << "b = " << b << std::endl;  // 输出 4294967295 (即 2^32 - 1)

    // 致命陷阱：循环条件永远为真
    for (uint32_t i = 10; i >= 0; i--) {
        // 当 i 减到 0 后，再减 1 会变成 4294967295，依然 >= 0，导致死循环！
        std::cout << i << std::endl;
    }
    return 0;
}
```



### 4. 什么时候用哪个？（实战建议）

| 类型                  | 推荐使用场景                                                 | 避免使用场景                                                 |
| :-------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **int32_t (有符号)**  | **绝大多数通用计算**（年龄、分数、索引、数学运算）。 这是默认首选。 | 无                                                           |
| **uint32_t (无符号)** | **明确表示“位掩码”**（如颜色值 `0xFFFFFFFF`）、**硬件寄存器**、**哈希值**、**或明确规定不能为负的协议字段**。 | **循环变量**（尤其是倒序循环）、**数组下标**（虽然常用，但`int`更安全，需注意溢出）。 |

> **现代C++核心指南（C++ Core Guidelines）建议**：除非有极强的理由（如位运算或与硬件交互），否则**优先使用有符号数**，即使它不能表示42亿这么大的正数，但能避免无数因为符号转换引发的隐晦Bug。
